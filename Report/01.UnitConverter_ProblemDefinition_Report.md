## 2. Mom Test 인터뷰 요약

인터뷰 규칙: 과거 사실만 질문 · 솔루션 언급 금지 · 모호한 답은 1회 추궁 · 솔루션 제안 시 불편으로 되돌림.

| # | 질문 (요지) | 답변 (요지) |
|---|-------------|-------------|
| 1 | 마지막으로 단위가 달라 숫자를 맞춘 때? | 수요일, 미국산 싱크대 32 inch vs 시공팀 실측 820 mm |
| 2 | 그때 구체적으로 뭘 했어? | 계산기 32×2.54, PDF 변환표(inch→cm만), 시공팀 카톡 확인 |
| 3 | 몇 분 걸렸어? | **15분+** (계산 1~2분, **확신·대기**가 대부분) |
| 4 | 맞다/틀리다 판정 기준? | 시공 실측 820 mm 기준; 스펙 **외경/내경** 해석 혼동 |
| 5 | 얼마나 자주? | **주 3~4번** |
| 6 | 가장 골치 아팠던 한 번? | feet 6.5 vs 6′-6″ 해석, 발주 **1시간 전**, **30분+** |
| 7 | 실수·위험 순간? | 6.5 feet 오해로 **거의 틀릴 뻔** → 재발주·일정 지연 리스크 |
| 8 | 포기·미룬 적? | 모바일 PDF 불편 → **대충 반올림** → 현장 **2 mm** 틈 문제 |
| 9 | (추궁) 2 mm 틈을 누가 문제 삼았어? | **시공팀 반장** (현장 사진) → 견적 담당 **책임** 이슈 |
| 10 | 시간 말고 가장 큰 비용? | **판정 책임·신뢰**; 같은 실수 **재현** 쉬움 |

## 3. 표면 문제 vs 진짜 문제

| 구분 | 한 문장 |
|------|---------|
| **표면 문제 (잘못된 정의)** | inch·feet·meter를 한 번에 바꿔 주는 **단위 변환 프로그램**을 만들면 견적·발주 단위 불일치 문제가 해결된다. |
| **진짜 문제** | 해외 스펙과 국내 실측·발주 단위가 섞인 상태에서 **확실한 기준 없이** 수동 계산·해석을 반복하다 **시간·오차·책임 리스크**가 반복 발생한다. |

### Mom Test 증거 3줄 (인터뷰 인용)

1. **“주 3~4번은 있어. 해외 가구·조명 견적 들어올 때마다 거의 그래.”**
2. **“15분 넘게 … 확신 못 해서 … 답 올 때까지 기다리는 시간이 대부분이었어.”**
3. **“거의 틀릴 뻔했어. 발주서 한 번 잘못 나가면 재발주·일정 지연까지 갈 수 있어서.”**

## 4. R-G-I-O

| 항목 | 내용 |
|------|------|
| **Role** | 해외 제품 스펙(inch·feet)과 국내 시공·발주 단위(mm·m)를 **같은 날 맞춰야 하는** 견적·발주 담당자 |
| **Goal** | **한 값** 입력으로 쓰는 **모든 등록 단위**에 대해 **같은 기준·같은 비율**로 환산해, 15~30분짜리 수동 확인·재계산·대기와 발주 오류 리스크를 줄인다 |
| **Input** | `단위이름:숫자` 문자열 (예: `meter:2.5`, `feet:6.5`); 잘못된 형식·음수·미등록 단위는 변환하지 않고 거절 |
| **Output** | 입력과 동일 물리량의 **등록된 전 단위 수치 목록** (기본: 줄 단위; 확장: JSON / CSV / 표 — 동일 결과의 다른 보기) |

---

## 5. 주제 (한 문장)

**해외 스펙과 국내 실측·발주 단위가 섞일 때, 손 계산·해석 반복으로 잃는 시간과 틀린 숫자 비용을, 한 번 입력으로 여러 단위를 일관되게 맞추는 것으로 줄인다.**

---

## 6. 성공 기준 (관찰 가능 · Mom Test 친화)

| # | 기준 | 관찰 방법 |
|---|------|-----------|
| 1 | **정확성** | `meter:2.5` → feet·yard가 README 비율과 허용 오차 내 일치; feet↔yard는 meter 경유로 모순 없음 |
| 2 | **신뢰(판정)** | 음수·형식 오류·미등록 단위는 결과 없이 **이유를 알 수 있는 메시지**만 반환 |
| 3 | **확장·재현** | 새 단위·비율 등록 후 기존 입력 방식 그대로 즉시 전 단위 변환; 깨진 설정은 잘못된 숫자 대신 명확한 실패 |
